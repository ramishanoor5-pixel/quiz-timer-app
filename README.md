# Quiz Timer App

## About the Project

The Quiz Timer App is a simple and interactive JavaScript application that allows users to set and control countdown timers. It is developed as part of my JavaScript Intermediate internship Task 4  to practice JavaScript concepts and build interactive web applications.

## Features

* **Custom Timer:** Choose from 30 seconds, 1 minute, or 5 minutes.
* **Start Timer:** Start the countdown with a button.
* **Pause Timer:** Pause the countdown whenever needed.
* **Reset Timer:** Reset the timer to its selected duration.
* **Keyboard Shortcuts:** Use the Space key to start or pause the timer and the R key to reset it.
* **Visual Alert:** Display an alert when the countdown reaches zero.
* **Audio Alert:** Play a sound when the timer ends.
* **Dynamic UI:** Update the timer display in real time.
